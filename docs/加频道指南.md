# 加频道指南（零代码版）

> 适用版本：FongMi/TV（FongMi-CatVod 同源）
> 适用机器：坚果 N3 / N3 Pro / N3 Ultra 等 Android 投影仪

## 一、加一个新频道需要做两件事

| 步骤 | 动作 | 位置 |
| --- | --- | --- |
| 1 | 复制一份新的 Spider 脚本 | `assets/spider/spider_xxxxxx.py` |
| 2 | 在 `config.json` 里加一行 | `assets/config/config.json` |

完成后只要重新打一次包即可。

---

## 二、拿到一份新的 Spider 脚本

Py Spider 在 GitHub / Telegram 群里大量流通，下面三个地方能稳定找到：

- **FongMi/TV Wiki / Examples**（[FongMi/TV](https://github.com/FongMi/TV) 官方 Wiki 有不少样例）
- **CatVodSpider 仓库**（关键字搜 `csp_Csp.py` / `PyUtil.py`）
- **TVBox 资源聚合群**（搜 `Py Spider` 即可）

## 三、在 config.json 里登记它

打开 `assets/config/config.json`，找到 `sites` 数组，加一项：

```json
{
  "key": "myfilm",                                    // 唯一 id，必须英文
  "name": "我的新频道",                                 // 显示在首页列表的标题
  "type": 3,                                          // 3 = Python 爬虫
  "api": "spider_myfilm.py",                          // 必须与文件名一致
  "ext": "https://example.com",                       // 传给 init(extend) 的 host
  "searchable": 1,                                    // 1 = 允许搜索
  "quickSearch": 1,                                   // 1 = 支持首页快速搜索
  "filterable": 1                                     // 1 = 支持按类型筛选
}
```

⚠️ 注意：

- `key` 不能与已有 20 个重复，建议用站点拼音或简短英文
- `ext` 可以留空，脚本会回落到 `Spider.host` 默认值
- 第一次添加建议 `filterable: 0`，省事；等跑通再打开

## 五、常见坑

| 现象 | 排查 |
| --- | --- |
| 首页看不到新频道 | 重新进壳子 → 设置 → 数据 → 还原初始配置；或重启 app |
| 报 `ModuleNotFoundError: Crypto` | 见《打包指南.md》第二节，需要在 `app/build.gradle` 启用 `pycryptodome` |
| 报 `No module named base.spider` | Chaquopy 路径没注入；确认脚本和 `base/` 在同一层 `assets/spider/` |
| 频道点开空白 | 99% 是 `init()` 没把 `self.host` 写正确，PC 跑 `print(s.fetch(s.host).status_code)` 看 200/301/403 |

## 六、批量管理建议

当频道超过 30 个时，建议你：

1. **拆文件**：每个站点一个 .py，不要 1 个 .py 写 10 个站点（性能差）
2. **开 DoH**：在 `config.json` 顶部 `doh` 已经默认 Google / Cloudflare，**保留这一段**
3. **加白名单**：把不常用站点的 `searchable: 0`、`quickSearch: 0`，只保留收藏
4. **导出分享**：在壳子里 `设置 → 数据 → 导出配置`，会得到一个 `*.txt`，
   别人粘进 `config.json` 的 `sites` 就能用

完成！打开壳子，新频道就在首页。
